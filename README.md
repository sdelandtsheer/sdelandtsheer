## Scientific software

### [pyPGLM — Probabilistic Graphical Logical Models](https://github.com/sysbiolux/pypglm)

A Python framework for mechanistic modeling of biological signaling networks, building on the probabilistic logical modeling approach introduced in FALCON.

It combines prior network knowledge with experimental perturbation data to estimate model parameters and investigate context-dependent signaling mechanisms.

- Network-constrained, interpretable models
- Parameter estimation, regularization, and uncertainty analysis
- Multi-context modeling across cell lines and experimental conditions
- Reproducible benchmarks and biological applications

[Repository](https://github.com/sysbiolux/pypglm) · [Scientific experiments](https://github.com/sysbiolux/pypglm/tree/main/examples) · [Reproducibility](https://github.com/sysbiolux/pypglm/blob/main/docs/reproducibility.md) · [Tests](https://github.com/sysbiolux/pypglm/tree/main/tests)

### [FALCON — Fast Contextualization of Logical Networks](https://github.com/sysbiolux/FALCON)

A MATLAB toolbox I co-developed for calibrating large-scale logical models of signaling pathways against experimental data.

FALCON provides optimization and regularization methods to contextualize prior-knowledge networks and investigate cell-specific signaling mechanisms.

Published in *Bioinformatics* (2017), with subsequent methodological developments published in *Frontiers in Physiology* (2018).

[Source code](https://github.com/sysbiolux/FALCON) · [Original publication](https://academic.oup.com/bioinformatics/article/33/21/3431/3897376) · [Regularization methods](https://www.frontiersin.org/articles/10.3389/fphys.2018.00550/full)

## Selected independent projects

I also enjoy building algorithms and software outside my main research field.

### [8-Pawn Chess](https://github.com/sdelandtsheer/8-pawn-chess)

An experimental chess variant and AI environment for investigating game-tree search, strategic evaluation, and algorithm design.

Includes multiple competing strategies, automated tournaments, and reproducible benchmarks. One evaluation compares strategies across 39,200 games.

[Code](https://github.com/sdelandtsheer/8-pawn-chess) · [Tournament results](https://github.com/sdelandtsheer/8-pawn-chess/blob/main/reports/width4-benchmark-10x/README.md)

### [FlashWords](https://github.com/sdelandtsheer/FlashWords)

A browser-based educational game exploring rapid visual recognition, working memory, and spelling.

Built with React and TypeScript, with automated tests, continuous integration, and a validated French-language stimulus corpus.

[Code](https://github.com/sdelandtsheer/FlashWords) · [Tests](https://github.com/sdelandtsheer/FlashWords/tree/main/tests)

### [Rubin Night Watch](https://github.com/sdelandtsheer/astramap)

An interactive astronomy visualization prototype exploring how large streams of telescope alerts could be inspected and prioritized.

Combines sky maps, light curves, anomaly scores, and object exploration in a browser interface. The current demonstration uses synthetic data rather than live observatory alerts.

[Code](https://github.com/sdelandtsheer/astramap) · [Methods](https://github.com/sdelandtsheer/astramap/blob/main/docs/methods.md)
